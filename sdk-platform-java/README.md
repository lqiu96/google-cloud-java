# sdk-platform-java

This directory in `google-cloud-java` contains the foundational modules for building Java client libraries for Google Cloud APIs:

- **[gapic-generator-java](./gapic-generator-java/README.md)**: the Protobuf compiler plugin to generate Java code.
  See [gapic-generator-java/DEVELOPMENT.md](./gapic-generator-java/DEVELOPMENT.md) for setup.
- **[gax-java](./gax-java/README.md)**: the runtime library required for Google Cloud client libraries,
  including the ones generated by `gapic-generator-java`.
- **[api-common-java](./api-common-java/README.md)**: foundational types and utilities for Google APIs
  (stability annotations, `ApiFuture`, path templates, and resource names).
- **[java-core](./java-core/README.md)**: shared core library for handwritten Google Cloud Java client libraries.
- **[java-showcase-3.25.8](./java-showcase-3.25.8/README.md)**: demonstration of the generated client
  library for the "Showcase" API.
- **[gapic-generator-java-bom](./gapic-generator-java-bom)**: the Bill of Materials for the libraries
  produced from this directory. This is used by [java-shared-dependencies](./java-shared-dependencies/first-party-dependencies/pom.xml).
- **[sdk-platform-java-config](./sdk-platform-java-config)**: shared Maven build configuration for `sdk-platform-java` modules.
